Assembled Example Pack

Everything is wired together.

This package gives you one clean structure with the aWavegent marketing layer, the modular business-page engine, the reusable section files, and two full JSON-driven examples you can expand.

Open Sales Homepage Open Full Restaurant Example Open Full Charter Example Open Lead Form Open Pricing Page Open Proof / Comparison

The restaurant and charter examples are the real important part. They are both built from the same template shell, the same section modules, and different data.json files. That is the reusable system.

Folder Structure

/css — marketing site design system
/base — shared business-page styles
/sections — modular page components
/examples/restaurant — full restaurant example
/examples/charter — full charter example
/sales — homepage + funnel pages
/docs — setup notes

To add another business, duplicate one example folder, replace data.json, and keep the same index.html. To add or remove sections, edit the sections array inside the JSON.
